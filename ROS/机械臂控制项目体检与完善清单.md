## 最高优先级问题

### 1. CMake 构建目前不可复现

现象：

```text
cmake --build build
MSBUILD : error MSB1009: 项目文件不存在。
开关: ALL_BUILD.vcxproj
```

原因：

`build/` 目录里只有 `CMakeCache.txt` 和 `CMakeFiles/`，没有正常生成 `ALL_BUILD.vcxproj`、`.sln` 或目标工程文件。

进一步日志显示 Visual Studio / MSBuild 在检测编译器时失败：

```text
error MSB6001: “CL.exe”的命令行开关无效。
System.ArgumentException: 已添加项。字典中的关键字:“PATH”所添加的关键字:“Path”
```

判断：

这不是 `JacobianSolver` 源码本身的问题，而是 Windows 环境变量里同时存在 `PATH` 和 `Path`，导致 MSBuild 读取环境变量时冲突。

建议：

- [ ] 不要继续沿用当前 `build/`
- [ ] 新建干净构建目录，例如 `build_vs` 或 `build_ninja`
- [ ] 优先尝试 Ninja / MinGW 或者在干净终端里重新配置 Visual Studio 环境
- [ ] 如果继续用 Visual Studio，先修复系统环境变量中重复的 `PATH` / `Path`

## 代码质量评价

### JacobianSolver 优点

- 使用 Eigen 的 `JacobiSVD` 做伪逆，方向是对的。
- 有输入维度检查。
- 有空矩阵检查。
- 有 tolerance 检查。
- 测试里覆盖了 identity、near singular、dimension mismatch。

### JacobianSolver 需要完善

- [ ] `tolerance` 现在是绝对阈值，后续可以改成相对阈值，例如 `tol * max(rows, cols) * max_singular_value`
- [ ] 需要测试非方阵矩阵，例如 `2x3` 或 `6x7`
- [ ] 需要测试零矩阵或秩亏矩阵
- [ ] 需要测试 `pseudoInverse(J) * J` 的近似性质
- [ ] 需要在 README 里解释奇异值过小为什么会导致关节速度放大

## 推荐的项目完善顺序

### Step 1：先修构建

目标：

- [ ] 能从空 build 目录完成 configure
- [ ] 能完成 build
- [ ] 能运行 `test_jacobian_solver`

验收命令：

```bash
cmake -S . -B build
cmake --build build
./build/test_jacobian_solver
```

Windows 下路径可能是：

```powershell
.\build\Debug\test_jacobian_solver.exe
```

---

### Step 2：补齐第一周核心模块

按这个顺序补：

1. `RobotState`
2. `SafetyLimiter`
3. `CubicInterpolator`
4. `TrajectoryBuffer`
5. `control_loop_demo`

每补一个模块，必须同时补：

- 头文件
- 源文件
- example / test
- CMake target
- README 说明

---

### Step 3：把 JacobianSolver 接入主线

不要让 `JacobianSolver` 孤立存在。它应该服务于机械臂控制问题。

建议新增一个 demo：

```text
examples/jacobian_velocity_demo.cpp
```

内容：

```text
给定 2 自由度机械臂雅可比 J
给定期望末端速度 v
用伪逆求关节速度 dq
经过 SafetyLimiter 限幅
更新 RobotState
打印结果
```

这样项目主线会从“数学工具”变成“控制链路”。

---

### Step 4：再进入 ROS2

不要现在直接跳 ROS2。建议等纯 C++ 控制库至少有下面这些文件后再迁移：

```text
include/robot_state.hpp
include/safety_limiter.hpp
include/cubic_interpolator.hpp
include/trajectory_buffer.hpp
include/jacobian_solver.hpp
src/robot_state.cpp
src/safety_limiter.cpp
src/cubic_interpolator.cpp
src/trajectory_buffer.cpp
src/jacobian_solver.cpp
examples/control_loop_demo.cpp
examples/test_jacobian_solver.cpp
README.md
```

进入 ROS2 时，第一版 `vel_to_pos_node` 可以先不用链接这个库，先跑通 ROS2 通信链路。跑通后再把 `SafetyLimiter` 和状态管理接进去。
