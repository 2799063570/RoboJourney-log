## 建议顺序

1. 先完成一个 `ament_cmake` C++ 包的发布、订阅、参数和 launch 闭环。
2. 再理解 QoS、DDS 与多机发现，避免只会运行却无法排错。
3. 最后将控制节点接到 URDF、`joint_states`、TF2 和 RViz2，再考虑 MoveIt2 或 ros2_control。
