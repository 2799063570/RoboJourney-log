
记录一下写数据生成程序的逻辑
## 初始化模型

从参数服务器中读取数据，构建机器人的运动学模型
```cpp
robot_model_loader::RobotModelLoader robot_model_loader("robot_description");
robot_model::RobotModelPtr kinematic_model = robot_model_loader.getModel();
```

| **对象名 (Object)**   | **作用 (What)**               | **关键用法 (How)**                 |
| ------------------ | --------------------------- | ------------------------------ |
| `RobotModelLoader` | **入口**。负责去 ROS 参数服务器找 URDF。 | `loader("robot_description")`  |
| `RobotModelPtr`    | **只读图纸**。存着连杆长度、关节限制。       | `loader.getModel()`            |
| `RobotStatePtr`    | **可写草稿**。用来改关节角度、算 FK/IK。   | `new RobotState(model_ptr)`    |
| `PlanningScenePtr` | **环境容器**。只有它能做**碰撞检测**。     | `new PlanningScene(model_ptr)` |
