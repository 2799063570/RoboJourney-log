# 学习引导 RRT-Connect 复习

## 问题定义

给定配置空间 $\mathcal C$、障碍区域 $\mathcal C_{obs}$、自由空间 $\mathcal C_{free}$、起点和终点，寻找一条完全位于自由空间且满足关节/运动约束的路径。机械臂通常在关节空间搜索，再通过正运动学和碰撞模型检查状态或边。

## RRT-Connect 主流程

1. 两棵树分别从起点和终点生长。
2. 从采样分布取得 $q_{rand}$。
3. 在树 A 中找最近节点，向采样点延伸一步；沿边做离散或连续碰撞检测。
4. 用树 B 贪婪地反复向新节点连接，直到到达、遇障或达到限制。
5. 交换两棵树，重复搜索；连接成功后拼接路径。

它通常比单向 RRT 更快找到可行解，但不是渐近最优算法。性能受采样策略、距离度量、步长、碰撞检测分辨率和最近邻结构影响。

## 学习引导模块

简历中的方法可按以下接口讲解：

```text
环境障碍物点云 + 起点 + 终点
→ 点云编码器提取环境特征
→ 条件生成模型学习可行路径分布
→ Transformer 融合环境、起终点与路径上下文
→ 批量产生高概率路径节点/骨架
→ 嵌入双向 RRT-Connect
```

模型提供的是采样先验，不应替代碰撞检测。任何预测节点和连接边都必须经过同一套有效性检查。

## 混合采样与完备性

可把采样分为三部分：学习分布、全空间均匀分布、对向树节点。学习采样提高命中有效通道的概率；对向树采样加快双树连接；均匀采样承担探索与失效回退。

严谨表述：如果在每次迭代中始终以非零概率从整个可行配置空间的绝对连续分布采样，并且扩展、连接和碰撞检测满足标准 RRT 的假设，那么学习偏置不会完全剥夺对任何有正测度区域的探索机会，因此可继承概率完备性的论证思路。有限时间内仍可能失败，且具体实现需要检查混合权重是否会衰减到零。

## 贪婪连接

预测节点可先形成候选骨架，但仍需逐段验证。所谓贪婪连接，是从一棵树的新节点连续向另一棵树或预测骨架推进，减少只扩展一步造成的迭代浪费。风险是对错误先验投入过多碰撞检测，因此应设置最大连接步数、失败回退和超时预算。

## 模型部分的高频追问

### 为什么使用 CVAE？

同一环境和起终点可能存在多条可行路径，输出是多模态分布。CVAE 通过条件变量约束生成，并用潜变量表达路径多样性，比单点回归更适合生成多个候选。

### Transformer 的作用是什么？

用于建模路径节点之间的长程依赖，并融合环境、起终状态与路径上下文。必须结合真实实现说明 token、位置编码和输出形式，不能只回答“注意力更强”。

### 如何防止网络输出碰撞节点？

训练时可加入碰撞/几何约束损失或过滤，但在线仍必须用规划器的状态与运动有效性检查；无效预测被拒绝并回退到其他采样源。

### 为什么不直接输出整条路径？

端到端路径可能不连续、碰撞或泛化失败。把学习模型作为采样先验，保留传统规划器的有效性检查和搜索回退，可靠性更高。

## 指标与公平对比

- 成功率：相同场景、超时、碰撞分辨率和硬件下成功的比例。
- 规划时间：明确是否包含模型推理、点云处理、路径简化和时间参数化。
- 路径质量：说明 1.031 rad 的定义；可以是关节空间累计转角，但必须给出公式。
- 额外报告：首次解时间、碰撞检测次数、节点数、P50/P95、不同狭窄度下表现。

建议消融：

| 组别 | 用途 |
|---|---|
| 原始 RRT-Connect | 传统基线 |
| 仅学习采样 | 检查先验收益与失效风险 |
| 学习 + 均匀 | 检查回退机制 |
| 学习 + 均匀 + 对向树 | 检查混合策略 |
| 完整方法去掉贪婪连接 | 检查连接机制贡献 |

## 失败模式

- 点云遮挡或分布外场景导致先验错误。
- 预测集中在窄小区域，降低探索多样性。
- 关节空间距离近但工作空间连杆扫掠碰撞。
- 步长过大导致窄通道穿越失败，过小则碰撞检测开销过高。
- 只统计成功样本的时间造成结果偏乐观。
