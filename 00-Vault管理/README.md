## 当前整理原则

- 根目录只放入口页。
- 项目主线放在 `ROS`。
- 运动规划算法放在 `motion_planning`。
- C++ 基础放在 `CPP`。
- 临时材料放在 `Inbox/待整理`。
- 空白、乱码、重复、位置不明的笔记不要继续扩写，先归类或重写。

## 每周维护清单

- [ ] 根目录是否只剩入口页
- [ ] `Inbox/待整理` 是否有可归档内容
- [ ] ROS 项目计划是否和实际进度一致
- [ ] 是否有构建产物、IDE 缓存进入 Git
- [ ] 是否有文件名不清楚或重复的笔记

## 写作规范

- 标题要能说明问题。
- 开头先写结论，再写细节。
- 概念笔记要有“用途、原理、命令/代码、常见错误”。
- 项目笔记要有“目标、步骤、运行方式、验收标准”。
- 学习计划要写当前状态，不要只写理想安排。
