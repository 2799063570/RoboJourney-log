- CMake 组织
- 数组、向量、矩阵数据结构
- 简单测试程序

## 机械臂项目所需模块

| 模块 | 作用 |
|---|---|
| `RobotState` | 保存关节位置、速度、时间戳 |
| `SafetyLimiter` | 对速度、位置、加速度做限幅 |
| `CubicInterpolator` | 生成平滑轨迹 |
| `TrajectoryBuffer` | 管理轨迹点队列 |
| `JacobianSolver` | 做运动学相关计算 |

优先把这些模块写成可以单独测试的 C++ 类，再接 ROS2 节点。

## 学习提醒

- 不要只抄语法，要写最小可运行例子。
- 每个类都写一个 `examples/test_xxx.cpp`。
- CMake 能稳定构建，比多写几个函数更重要。
- 控制项目里，接口清楚比算法复杂更重要。
