## 本周学习状态

你现在处在计划的第 3 周，但 ROS2 基础还需要补齐。当前实际掌握情况更接近：

- ROS1 有基础
- ROS2 了解了功能包创建
- ROS2 节点、话题、参数、launch、TF2、RViz2 还需要系统练习
- 机械臂控制项目目前还在 C++ 控制库和 ROS2 接入前期

因此后续学习不要急着跳 MoveIt 或复杂规划，先把 ROS2 的最小闭环跑通。
