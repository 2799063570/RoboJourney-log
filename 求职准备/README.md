## 使用方法

- 每天从复习计划中选取任务，不再从旧计划中随机挑内容。
- 每学一个主题，必须留下“口述答案、白板推导、可运行证据”中的至少两项。
- 面试题答案只作答题骨架；涉及个人分工、实现细节和指标时，以代码、实验日志或论文稿为准。
- 每周六做一次模拟面试；周日只复盘错题、补证据和休息。
